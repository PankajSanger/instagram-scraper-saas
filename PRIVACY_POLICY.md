# Privacy Policy

Effective date: 2026-03-08

## Overview

Instagram Comments Scraper processes data visible in the Instagram tab that you open and run the extension on.

## Data We Access

- Post/reel comments available on the active Instagram page.
- Optional commenter profile fields when profile enrichment is enabled.

## Data Storage

- The extension generates a CSV file and downloads it to your local device.
- This extension does not transmit collected data to our servers by default.
- This extension does not sell personal data.

## Permissions

- `activeTab`: required to run scraping logic only on your current tab.
- `scripting`: required to inject scraper logic into the current tab.
- Host permission for `https://www.instagram.com/*`: required to operate on Instagram pages.

## Third Parties

This extension interacts with Instagram endpoints through your browser session to collect page data.

## Security

Use this tool only on accounts and data you are authorized to access.

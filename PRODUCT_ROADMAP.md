# Product Roadmap

## Phase 1: Stabilize Extension

- Break `popup.js` into modules (`ui`, `scraper`, `csv`, `network`).
- Add unit tests for parser and CSV escaping.
- Add robust retry/backoff metrics and error categories.

## Phase 2: Launch Readiness

- Create website landing page and documentation.
- Add support email and issue triage workflow.
- Publish Chrome Web Store listing with screenshots and policy links.

## Phase 3: SaaS Productization

- Add backend API for saved jobs and downloadable history.
- Add authentication and API key management.
- Add pricing plans and billing integration.
- Add monitoring and abuse prevention.

## Phase 4: Growth

- Add team collaboration and scheduled scrapes.
- Add integrations (Google Sheets, webhooks, CSV to cloud).
- Add analytics dashboard and export templates.
